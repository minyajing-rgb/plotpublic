总计 **179 张独立 PNG**。上述目录的“状态”只表明文件用途；探索图和参考图并不自动获得投放许可或产品真实性背书。图片尺寸、SHA-256、原始文件名、来源和重复文件位置均在 [`assets/manifest.json`](assets/manifest.json)。预览页使用小尺寸 PNG 缩略图，点击可打开仓库中的完整原图。

另有 7 张已批准的粉黑白图保存在 `minyajing-rgb/astro` 仓库的 `plot` 分支；这 7 张的原始二进制文件现都已纳入本库，其中 1 张与广告探索图重复。清单的 `already_on_github` 列出文件名、Git blob SHA 和本库路径。

原 README 中六张英文关系／亲子分享卡是**计划文件名**，并非已经生成并上传的 PNG。后续制作完成后再加入本库，避免把创意计划误写成成品。
