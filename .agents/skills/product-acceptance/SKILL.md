Read product-definition and full approved PRD/mockups/flows/architecture. Freeze exact repo/commit/build/URL/environment/time/browser/device/locale/width. ALL actual page instances, nested branches/tabs/modals/controls and required states are denominator; diff router and visible links, add discovered routes. PASS/FAIL/BLOCKED/NA_WITH_REASON, untested BLOCKED; report covered/total.
Complete PAGE_REVIEW_CARD per page: requirement/flow/mockup IDs; expected/actual; desktop/mobile actual-reference pairs; content/source/translation/imagery; every control's destination/side effect; all required states; accessibility; console/network/private access/metadata; exact evidence commit/defect IDs. Open pixels beside approved mockups: hierarchy/spacing/type/contrast, original images/crop/readability, overlap/clipping/long text/sticky bars, unique accessible names/keyboard/focus return/zoom/touch/reduced motion. Captured screenshots, DOM tests, HTTP200 and builder claims do not certify visuals. Previews are not full-resolution originals; emulated widths are not physical-device QA.
Exercise positive/alternative/failure paths: empty/invalid/long input, loading/success/no-results/error/timeout/offline/retry, denied storage/permissions, guest/auth, cancel/back/refresh/deeplink/repeated actions. Observe real state/network; applicable auth/RLS/data/model/forms/payments tested safely, no unauthorized charges/messages/private writes or weakened security. Review visitor value, architecture/privacy/locales/SEO/measured performance.
DEFECTS.json: severity, page/state/requirement, reproduction, expected/actual, evidence, owner, fixing commit, RETEST and regressions. P0 security/data loss; P1 missing/broken required flow or essential visual evidence/misleading success; P2 quality. Fix/retest; untested fixes remain open. Gate B implemented/built. Gate C INTERNALLY_ACCEPTED only full coverage+actual visual inspection+zero open P0/P1+explicit P2 exceptions. Otherwise NOT_READY with precise remaining scope, never silent waiver.
Gate D LIVE_VERIFIED only after authorized release: actual published/custom domains, redirects/body/title/asset hashes vs tested build; all live routes/locales/critical flows, console/network/canonical/lang/OG/SEO, auth and rollback. SPA200 may be wrong page. Missing candidate NOT_DEPLOYED; preview/rebuilt production are separate targets. Never publish or repeat backups to satisfy testing.
Reuse evidence only when diff proves page AND shared data/styles/translations unchanged; unknown mappings fail closed. Label method/version. Deliver only self-checked candidate with real previews, coverage, defects and exact build. Do not repeatedly ask owner to request review. Templates at pinned canonical .agents/skills. COPIED, ACTIVATION_TESTED and AUTOMATION_RUNNING are distinct; repository files are not automatic global runtime activation.
